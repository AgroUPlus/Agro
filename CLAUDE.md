# Agro

## AI Tools, Authorship and Non-Appropriation

- AI models and automated code agents are assistive utilities only. They are **not** authors or contributors.
- **Do not add** `Co-Authored-By` trailers, "Generated with" notices, or other metadata referencing AI models or tools to git commit messages or pull request descriptions.
- No AI vendor or automated system acquires ownership, copyright, or licensing claims over project code. Any contribution — AI-assisted or not — is still subject to [`CLA.md`](CLA.md).
