architecture Architecture

A unified self-hosted music ecosystem.

Agro bridges your music life across all devices without big tech snooping, telemetry, or walled gardens.

Playback handoff: Transfer active queues, playback progress, and seek positions seamlessly between phone and computer in real time.

Private social listening: Share live now-playing presence and host synchronized Jam sessions with friends via direct recipient-key encryption.

Direct spool relay: Peer-to-peer file staging with zero server decoding or bandwidth waste.

verified_user Security

Private by default. Safe by design.

key
Zero-knowledge Vault

Metadata and credentials are sealed client-side before touching the wire. The server stores ciphertext and holds zero keys.

fingerprint
Strong Credential Model

Passphrases hashed using Argon2id. Scoped device tokens are 256-bit CSPRNG, stored strictly as SHA-256 hashes.

shield_lock
Cryptographic Isolation

Presence and listen-along streams are individually encrypted per recipient public key, preventing any server leakage.

rocket_launch Deployment

Two ways in

Self-host binary
Run your own server

One lightweight binary with embedded SQLite. Starts up in seconds under systemd, Docker, or behind a reverse proxy.

# Build dashboard, then binary
cd dashboard && npm ci && npm run build
cd .. && cargo build --release

# Run
PORT=1674 AGRO_LIBRARY_ROOT=/srv/music \
  ./target/release/agro
