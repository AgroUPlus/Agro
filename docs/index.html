A simple, open-source music ecosystem

Agro is the server behind Wanda on Android and Wander on the desktop. Both apps play your music on their own; connect them to Agro and they share handoff, jam rooms, friends and stats. Open source under AGPL-3.0.

verified_user Security

Private by default. Safe by design.

key
Zero-knowledge Vault

Metadata and credentials are sealed client-side before touching the wire. The server stores ciphertext and holds zero keys.

fingerprint
Strong Credential Model

Passphrases hashed using Argon2id. Scoped device tokens are 256-bit CSPRNG, stored strictly as SHA-256 hashes.

shield_lock
Cryptographic Isolation

Presence and listen-along streams are individually encrypted per recipient public key, preventing any server leakage.

rocket_launch Deployment

Two ways in

Run the binary yourself, or sign in to the hosted instance. Either way the clients, keys and libraries behave identically.

Self-host binary
Run your own server

One lightweight binary with embedded SQLite. Run it in Docker or install it natively, no build needed.

# Docker
docker run -d --name agro -p 8700:8700 \
  -v agro_data:/opt/agro/data \
  -v ~/Music:/srv/music:ro \
  ghcr.io/agrouplus/agro

# Or native on Linux (no root)
curl -fsSL https://raw.githubusercontent.com/AgroUPlus/Agro/main/scripts/install.sh | sh

Then open localhost:8700 and paste the one-time setup token from the log (docker logs agro) to create your admin account.
