What it is

A unified self-hosted
music ecosystem.

Agro connects your personal music life across all your devices without relying on third-party servers or proprietary clouds. Built with a focus on privacy and end-to-end encryption, it unifies:

Playback handoff: Transfer active queues, playback positions, and tracks between desktop and mobile with zero effort.

Social and listen-along: Now-playing presence is encrypted per-friend using their individual device public keys. The server merely relays ciphertexts it cannot inspect.

Peer-to-peer library relay: Direct device-to-device file streaming and media server spooling with cryptographic verification.

Zero-knowledge architecture: Powered by SQLite, an embedded modern web dashboard, and client-sealed vault credentials.

Security

Private by default. Safe by design.

Agro is engineered so the server never holds your secrets or listening habits. Every layer enforces strict cryptographic boundaries.

🔒
Zero-knowledge vault & E2EE

Settings and now-playing metadata are sealed client-side before leaving the device. The server stores only encrypted payloads and holds no decryption keys.

E2EE · HKDF-SHA256
🔐
Strong credential model

Passphrases use Argon2id hashing to resist dictionary attacks. Device tokens are 256-bit CSPRNG, stored only as SHA-256 hashes.

Argon2id · SHA-256
🧪
Hardened cryptographic boundaries

Presence payloads are sealed per recipient public key, and automated boundary test suites verify isolation on every single commit.

cargo test · Isolated keys

Run your own server

One lightweight binary with embedded SQLite. Starts up in seconds under systemd, Docker, or behind a reverse proxy.

# Build dashboard, then the binary
cd dashboard && npm ci && npm run build
cd .. && cargo build --release

# Run
PORT=1674 AGRO_LIBRARY_ROOT=/srv/music \
  ./target/release/agro
